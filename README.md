# Weather App

Десктопное приложение для отображения текущей погоды и прогноза на 3 дня. Определяет местоположение пользователя, сохраняет историю запросов и поддерживает переключение между светлой и тёмной темами.

## Функциональность

- **Определение местоположения** — автоматическое определение города по IP-адресу
- **Поиск по названию** — ручной ввод города для получения погоды
- **История запросов** — сохранение последних 7 городов в базе данных SQLite
- **Прогноз погоды** — отображение текущей погоды и прогноза на 3 дня
- **Тёмная тема** — переключение между светлой и тёмной темами интерфейса

## Технологии

- **Python** — основной язык разработки
- **PySide6** — графический интерфейс (официальный Qt-фреймворк)
- **Qt Designer** — визуальное проектирование интерфейса
- **SQLite** — база данных для хранения истории
- **Requests** — HTTP-запросы к внешним API
- **PyInstaller** — создание исполняемого файла `.exe`

## Используемые API

| Сервис                                       | Назначение                         |
| -------------------------------------------- | ---------------------------------- |
| [ipify](https://www.ipify.org)               | Получение публичного IP-адреса     |
| [ip-api.com](https://ip-api.com)             | Определение города и страны по IP  |
| [Geoapify](https://www.geoapify.com)         | Поиск координат по названию города |
| [OpenWeatherMap](https://openweathermap.org) | Данные о текущей погоде и прогнозе |

## Установка и запуск

### 1. Клонирование репозитория

```
git clone https://github.com/Dimasik2007123/weather-app.git
cd weather-app
```

### 2. Установка зависимостей

```
pip install pyside6 requests pyinstaller
```

### 3. Запуск приложения

```
python main.py
```
